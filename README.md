📊 Store Annual Sales Dashboard
🔹 Project Overview
This project analyzes one year of store sales data using Microsoft Excel.
An interactive dashboard was created using Pivot Tables, Pivot Charts, and Slicers.
🔹 Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Calculated Fields
🔹 Dataset Details
One year sales data
Includes columns: Date, State, Gender, Age Group, Channel, Order Status, Revenue
Over 30,000 transactions analyzed
🔹 Key Insights
Women contribute majority of sales.
Adult age group generates highest revenue.
Maharashtra is the top performing state.
Amazon is the highest performing channel.
Delivery success rate is above 90%.
